# 🎱 Lotto

> Spring Boot를 활용한 로또 구매 및 관리 웹 프로젝트

## 📌 프로젝트 소개

로또 구매와 당첨 결과를 관리하고,
사용자의 로또 구매 내역을 확인할 수 있는 웹 서비스를 개발합니다.

현재 프로젝트 설계 및 개발을 진행하고 있습니다.

## 🛠️ Tech Stack

### Backend
- Java 17
- Spring Boot 3.x
- Spring Data JPA

### Database
- MySQL 8.x

### Tools
- Git
- GitHub
- IntelliJ IDEA
